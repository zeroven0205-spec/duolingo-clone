## 1. 数据库迁移（必做）

新增 6 个字段，全部 nullable 或带默认值，老数据无需手动填充：

| 表 | 字段 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `user_progress` | `streak_protection_until` | `timestamp` | `NULL` |
| `user_progress` | `xp_boost_until` | `timestamp` | `NULL` |
| `user_progress` | `points_weekly` | `integer` | `0` |
| `user_progress` | `points_monthly` | `integer` | `0` |
| `user_progress` | `weekly_reset_at` | `timestamp` | `NULL` |
| `user_progress` | `monthly_reset_at` | `timestamp` | `NULL` |

### 步骤

```bash
# 1) 本地生成迁移文件
pnpm drizzle-kit generate

# 2) 在 staging 数据库先 dry-run
pnpm drizzle-kit push --config=drizzle.config.ts

# 3) 生产环境用 SQL 迁移文件
psql "$DATABASE_URL" < drizzle/0001_*.sql
```

迁移本身零风险：所有字段都可空或带默认，不需要 backfill。

## 2. 环境变量（必做）

`scripts/verify.sh` 里的 `next build` 步骤要求 `DATABASE_URL`。当前本地缺此变量，构建到 page-data 收集阶段会失败（与代码无关，仅环境问题）。

- **Vercel / 部署平台**：确认 `DATABASE_URL`（Neon Postgres URL）已配置。
- **本地构建**：复制 `.env.example` → `.env` 并填入 Neon URL。
- **Clerk**：`NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` + `CLERK_SECRET_KEY` 必须存在。
- **Stripe**：`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`、`NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`。
- **PostHog**：`NEXT_PUBLIC_POSTHOG_KEY`、`NEXT_PUBLIC_POSTHOG_HOST`（可选，但 analytics 事件会丢）。

## 3. 关键业务规则上线确认

| 项 | 期望行为 | 验证方式 |
| --- | --- | --- |
| Streak Freeze 1 天保护 | 用户跨过 1 天未登录后，`streakProtectionUntil` 自动清空且 streak +1（不重置） | 单元测试 + staging 手动跑 `updateStreakAndClaimRewards` |
| Streak Shield 7 天保护 | 同上，但 7 天内任意 1 次断签都被吸收 | staging 手动改 `streakProtectionUntil` 验证 |
| XP Boost | `xpBoostUntil` 在 `completeLesson` 期间可用于判定 2× XP 奖励 | 当前 `completeLesson` 未读取该字段，**遗留工作**见 §6 |
| 周/月榜 | 排行榜顶部切换 tabs，数据按 `pointsWeekly` / `pointsMonthly` 排序 | 在 staging 给两个用户分别 +XP，看顺序 |
| 周/月计数重置 | `completeLesson` 中检测 `weeklyResetAt`/`monthlyResetAt` 超 7/30 天则清零 | 直接改 DB 时间戳验证 |
| Hearts Pack 上限 | `hearts_pack` 后 `hearts ≤ MAX_HEARTS + 5`，**不是** `MAX_HEARTS` | 购买后 hearts 应 > 5（如果是 free 用户） |
| Shop 积分不足 | `< item.price` 时弹 `积分不足` toast，按钮 disabled | UI 验证 |
| Quest 庆祝 | 首次跨过 20/50/100/250/500/1000 XP 时 confetti，sessionStorage 防重 | 同一会话内反复进出 `/quests` 不再触发 |
| Streak 里程碑 | 进入 `/learn` 时若 `streak ∈ {3,7,30,100,365}` 触发 confetti + 徽章 | staging 把 streak 改成 7 看效果 |

## 8. 回滚方案

如上线后出现严重问题，按严重程度分两种：

**轻量（功能 bug）**：通过 §4 feature flag 关停受影响功能，无需回滚代码。

**严重（数据损坏 / 性能）**：
```bash
git revert <v2.1.0-commit-sha>
pnpm db:push --force   # 仅当 schema 也要回滚
```
新字段均为 nullable / 默认值，**降级后不会破坏老数据读取**。
