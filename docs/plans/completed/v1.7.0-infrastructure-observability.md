### LING-P1-PWA-1 · PWA 离线支持

```typescript
const withPWA = (await import("@ducanh2912/next-pwa")).default({
  dest: "public",
  disable: process.env.NODE_ENV === "development",
  register: true,
  skipWaiting: true,

const nextConfig = {
  reactStrictMode: true,
```

### LING-P1-POSTHOG-1 · PostHog 接入

**现状**: 未实现

**修复**:

1. 安装:
```bash
pnpm add posthog-node
```

2. 创建 `lib/analytics.ts`:
```typescript
import { PostHog } from "posthog-node";

const posthog = new PostHog(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
  host: process.env.NEXT_PUBLIC_POSTHOG_HOST || "https://app.posthog.com",
});

export default posthog;
```

3. 关键事件埋点（修改现有 actions）:

```typescript
// actions/user-progress.ts
import posthog from "@/lib/analytics";

// upsertUserProgress 中
posthog.capture({
  distinctId: userId,
  event: "user_registered",
  properties: { plan: "free" },
});

// reduceHearts 中（红心耗尽时）
if (currentUserProgress.hearts === 1) {
  posthog.capture({
    distinctId: userId,
    event: "hearts_exhausted",
    properties: { streak: currentUserProgress.streak },
  });
}
```

**关键事件**:
| 事件 | 触发时机 | 属性 |
| ---- | -------- | ---- |
| `user_registered` | 注册完成 | plan: free |
| `lesson_completed` | 课时完成 | lesson_id, course_id, score |
| `subscription_started` | 付费开始 | plan, mrr |
| `hearts_exhausted` | 红心耗尽 | streak (转化关键点) |
| `churn_risk` | D7 无登录 | days_inactive |
