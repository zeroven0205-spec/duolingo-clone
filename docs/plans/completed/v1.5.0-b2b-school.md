### LING-P0-B2B-1 · 多租户 SaaS 架构

**目标**: 一套实例支撑多个机构/学校/企业客户

**技术方案**:
```typescript
// 中间件层：提取 tenant_id
// 每个 API 增加 tenantId 过滤
// Clerk userId → tenant membership 映射

// lib/tenant.ts
export async function getTenantId(userId: string): Promise<string | null> {
  const membership = await db.query.tenantMembers.findFirst({
    where: eq(tenantMembers.userId, userId),
  });
  return membership?.tenantId ?? null;
}

// 所有数据查询增加 tenantId 过滤
export const getUserProgress = cache(async () => {
  const { userId } = await auth();
  const tenantId = await getTenantId(userId);
  // SELECT * FROM user_progress WHERE user_id = $1 AND tenant_id = $2
});
```

**数据库变更**:
```sql
-- 新增租户表
CREATE TABLE tenants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  plan TEXT DEFAULT 'free',  -- free | school | enterprise
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE tenant_members (
  tenant_id UUID REFERENCES tenants(id),
  user_id TEXT NOT NULL,
  role TEXT DEFAULT 'student',  -- admin | teacher | student
  PRIMARY KEY (tenant_id, user_id)
);
```

## P1 功能项（增长分析）

### LING-P1-ANALYTICS-1 · PostHog 自托管接入

**目标**: 隐私合规的数据分析（国内无 PostHog Cloud）

**部署**:
```bash
docker run -d \
  --name posthog \
  -p 6333:8000 \
  -e DATABASE_URL=postgresql://... \
  -e REDIS_URL=redis://... \
  -v posthog_data:/data \
  posthog/posthog:latest
```

**关键事件埋点**:
```typescript
// actions/user-progress.ts
import { posthog } from '@/lib/analytics';

// 注册
posthog.capture('user_registered', { plan: 'free' });

// 课时完成
posthog.capture('lesson_completed', {
  lesson_id: lesson.id,
  course_id: course.id,
  score: percentage,
});

// 订阅开始
posthog.capture('subscription_started', {
  plan: 'plus',
  mrr: 30,
});

// 红心耗尽（关键转化点）
posthog.capture('hearts_exhausted', {
  user_id: userId,
  current_streak: streak,
});
```

### LING-P1-ANALYTICS-2 · 关键指标 Dashboard
