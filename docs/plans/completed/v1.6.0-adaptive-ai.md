## ✅ P1 — 自适应学习 (已完成)

### LING-P1-ADAPT-1 · Spaced Repetition 算法 ✅

**状态**: 已实现 `lib/spaced-repetition.ts`

**实现内容**:
- Leitner Box 系统 (0-4 级)
- SM-18 ease factor 算法
- `calculateNextReview()` - 根据答题正确性计算下次复习时间
- `getDueCards()` - 获取到期复习的单词
- `createWordCard()` - 创建新单词卡

### LING-P1-ADAPT-2 · 复习队列 API ✅

**状态**: 已实现 `app/api/review-queue/route.ts`

**端点**:
- `GET /api/review-queue` - 获取待复习单词
- `POST /api/review-queue` - 提交复习结果

**数据库**: `db/schema-word-progress.ts` (userWords, challengeWords, wordReviewLog)

---

## ✅ P2 — AI 发音评估 (已完成)

### LING-P2-SPEECH-1 · Web Speech API 基础 ✅

**状态**: 已实现 `lib/speech评估.ts`

**实现内容**:
- `isSpeechRecognitionAvailable()` - 检测浏览器支持
- `评估发音()` - 启动语音识别并评估发音
- `计算文本相似度()` - Levenshtein 距离算法
- `获取反馈()` - 根据分数返回反馈信息

**限制**: 需要客户端 Web Speech API 支持
