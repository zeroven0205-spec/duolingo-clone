# Lingo 产品路线图

> 基于 2026-07-02 深度测试报告 + 竞品分析制定
> 版本: v2.0.0 (Engineering Quality)

---

## 产品定位

**差异化定位**: 开发者友好的语言学习平台底座，面向 EdTech 开发者、内容创作者和教育机构，而非正面对抗 Duolingo 大众市场。

**核心价值**: 开源 + 可定制 + 多语言 + 游戏化机制

### Phase 1: 稳定增强期 (Q3 2026)

**目标**: 完善游戏化、内容扩展、体验提升

#### v2.1.0 — 游戏化完善

| 功能 | 描述 |
| ---- | ---- |
| Streak 可视化 | 火焰图标 + 天数 + 奖励提示 |
| 每日任务系统 | 任务完成动画、进度展示 |
| 商店功能 | 宝石购买/兑换心 |
| 排行榜 | 周榜/月榜/总榜切换 |

#### v2.2.0 — 内容扩展

| 功能 | 描述 |
| ---- | ---- |
| 课程扩充 | 每门语言 5+ 单元 |
| 新增语言 | 韩语、德语 |
| 新题型 | 音频听写、跟读 |
| CMS 后台 | 非技术人员可维护课程 |

#### v2.3.0 — 体验提升

| 功能 | 描述 |
| ---- | ---- |
| PWA 离线 | 完整离线缓存 |
| 暗色模式 | 主题切换 |
| A11y | 键盘导航、焦点管理 |
| 动画优化 | Framer Motion |

### Phase 2: AI 增强期 (Q4 2026)
