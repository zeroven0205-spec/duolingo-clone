## 三、详细功能说明

### 3.1 课程体系（Course）

- **Course** → **Unit** → **Lesson** → **Challenge** → **ChallengeOption** 四级结构
- 用户选择一门课程（西班牙语）后，按单元顺序解锁课时
- 支持多门语言课程并行（用户可切换 activeCourse）

| 字段 | 说明 |
| ---- | ---- |
| `courses` | 课程表（title, imageSrc） |
| `units` | 单元表（属于某课程，含顺序） |
| `lessons` | 课时表（属于某单元，含顺序） |
| `challenges` | 挑战题（属于某课时，含题目类型） |
| `challengeOptions` | 选项表（text, correct, imageSrc, audioSrc） |

**Challenge 类型：**
- `SELECT`：四选一选择题（文字/图片/音频）
- `ASSIST`：填空题（用户输入正确单词）

### 3.2 学习进度（UserProgress）

- 记录每个用户的 `hearts`（红心）、`points`（积分）、当前课程
- 每答错一题扣 1 红心；红心耗尽无法继续答题
- `hearts` 默认 5 颗，通过每日任务或购买补充
- `points` 累计用于商店兑换或排行榜排名

### 3.3 订阅体系（UserSubscription）

- **Plus/Pro 订阅**：Stripe 驱动，自动续费
- 订阅用户享受：无限红心、无广告、专属功能
- `stripeSubscriptionId` + `stripePriceId` 与 Stripe Billing 同步
- Webhook 实时处理续费/取消事件

### 3.4 游戏化机制

| 模块 | 机制 | 说明 |
| ---- | ---- | ---- |
| **红心系统** | 5颗上限 | 答错扣心，心耗尽禁止学习 |
| **积分系统** | 持续累加 | 完成课时获得，可兑换红心 |
| **排行榜** | Top 10 | 按积分降序，展示社区学习排名 |
| **任务系统** | 每日目标 | 如：获得 50 XP（QUESTS 常量表） |
| **商店** | 积分兑换 | 用积分补充红心 or 升级 Plus |

### 3.5 管理后台（React Admin）

- 全栈 CRUD：课程、单元、课时、挑战题管理
- 无需写代码，内容运营可直接维护课程内容
- 支持图片/音频题配置（`imageSrc`, `audioSrc`）
